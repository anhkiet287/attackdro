W&B and handoff rules

online main runs · no silent fallback

W&B policy

operation-class specific
  • MAIN_RUN — online only; verify auth, project, entity, run name, and tags.
  • SMOKE / VALIDATION / DEBUG — offline or disabled only when explicitly approved.
  • EVAL / AUDIT — use the exact contracted mode.
  • W&B_SYNC — always separately authorized.

Handoff is not authority

summary helps; sources still win
  • Routing advice — never authorizes the next agent.
  • Human approval — required before launch or protocol/claim changes.
  • Source verification — handoff summaries never replace current files and artifacts.
