# WORK_FLOWS.md — operating rules (rules only; rationale lives in PROGRESS/MEMORY)

## Protocol & eval
1. **Locked protocol** ε = (ℓ∞ 0.03, ℓ2 0.5, ℓ1 12), CIFAR-10, PreActResNet-18, train == eval, `configs/base.yaml`. Do **not** change without Kiet's approval.
2. Metric = **worst-case union** robust acc (per-sample AND over 3 norms); union ≤ min per-norm.
3. Every number comes from `eval_union` / `eval_standard_pack`. **APGD (CE+T), n=1000** for iteration; **full `standard` AutoAttack only for finalists** (scoped). Absolute train/eval parity.
4. Any integrated baseline is evaluated **only** through our harness (parity invariant).

## Experiments
5. **Card first:** an E1 experiment card (in `EXPERIMENT_CARDS_P2.md`) with a **pre-registered prediction + decision rule** before any run. One card = one config = one variable changed.
6. **≤ 2 trainers on the GPU** at once. Long runs go in named tmux sessions with file-based gates (never trust `pgrep` on wrapper command lines).
7. **1 seed to probe; 3 seeds** for a config with signal; **20 seeds + Wilcoxon/BH-FDR** only for the final winner (P3).
8. No win is declared before **3 seeds + `standard` AutoAttack**.

## Results integrity
9. **Never fabricate a number.** Anything not on disk is reported *missing*, not estimated. `docs/EXPERIMENT_TABLE.md` is generated by `scripts/make_experiment_table.py` and must never be hand-edited.
10. **3 tiers, never mixed:** tier-1 in-house recipe-controlled · tier-2 checkpoint re-evals (`*`) · tier-3 ‡cited (protocol may differ, e.g. ε∞=8/255). Cross-tier comparisons are labelled, never implied-equal.
11. Every run: append an **E8 RESULT block** to `PROGRESS.md`; update `PROJECT_MEMORY.md` §5/§9 if a finding changes.

## Claims
12. Claim ladder: **C1** mechanism (F4–F6) + **F7** eval corrections + **C2** = a simple cheap adaptive weighting *reaching* the 43.9–44.6 SOTA cluster, **not exceeding it**. "match/beat SOTA" is banned.
13. Honesty > pretty numbers; mechanism > leaderboard; a rigorous negative result is an asset.

## Hygiene
14. Nothing leaves the repo (no external uploads) without explicit approval. No `git` force-push. In autopilot: no `base.yaml` edits, no >2 trainers, no new cards, no full-`standard` runs.
15. Dev/diagnostic scripts live in `scripts/dev/`; only the paper entry points sit at `scripts/` top level.
